# Ações do Usuário por Caso de Uso - Sonarfy

Com base no diagrama de casos de uso do sistema **Sonarfy**, esta documentação detalha a ação realizada pelo usuário em cada um dos casos de uso mapeados.

## 1. Sistema de Cadastro
* **1.1 Cadastrar usuário:** O usuário informa seus dados pessoais (como nome, e-mail, senha) para registrar uma nova conta no sistema.
* **1.2 Gerenciar cadastro:** O usuário acessa a central de gerenciamento de sua conta.
* **1.3 Alterar cadastro:** O usuário edita e atualiza as informações do seu perfil de cadastro.
* **1.4 Alterar senha:** O usuário fornece sua senha atual e define uma nova senha de acesso.
* **1.5 Desativar cadastro:** O usuário opta por desativar temporariamente sua conta na plataforma.
* **1.6 Excluir cadastro:** O usuário solicita a exclusão definitiva de sua conta e dados do sistema.

## 2. Sistema de Login
* **2.1 Fazer login:** O usuário insere suas credenciais (e-mail e senha) para autenticar-se na plataforma.
* **2.2 Fazer logout:** O usuário encerra sua sessão ativa no sistema.
* **2.3 Recuperar senha:** O usuário solicita a recuperação de acesso informando seu e-mail cadastrado para receber instruções de redefinição.

## 3. Sistema Social
* **2.4 Buscar usuários:** O usuário digita termos de busca para encontrar outros perfis na plataforma.
* **2.5 Seguir usuário:** O usuário escolhe começar a acompanhar as atualizações de outro perfil.
* **2.6 Deixar de seguir usuário:** O usuário cancela o acompanhamento de um perfil que seguia.
* **2.7 Visualizar seguindo:** O usuário consulta a lista de perfis que ele próprio segue.
* **2.8 Visualizar seguidores:** O usuário consulta a lista de pessoas que seguem o seu perfil.
* **2.9 Visualizar perfil:** O usuário clica para ver os detalhes do perfil de um usuário (próprio ou de terceiros).
* **2.10 Alterar perfil:** O usuário acessa as opções de personalização da sua página de perfil.
* **2.11 Alterar bio:** O usuário edita o texto de biografia do seu perfil.
* **2.12 Alterar avatar:** O usuário faz o upload ou troca a imagem de avatar do perfil.
* **2.13 Alterar capa:** O usuário troca a imagem de capa/fundo do seu perfil.

## 4. Sistema de Feed
* **4.1 Visualizar feed:** O usuário acessa a tela principal para ver as publicações e atividades recentes.
* **4.2 Visualizar feed pessoal:** O usuário visualiza apenas as publicações e atividades geradas por ele mesmo.
* **4.3 Visualizar feed de usuários seguidos:** O usuário visualiza as publicações e avaliações postadas pelas pessoas que ele segue.
* **4.4 Atualizar feed:** O usuário solicita a atualização manual do feed para carregar novos conteúdos.

## 5. Sistema de Avaliação
* **5.1 Pesquisar no catálogo:** O usuário busca por itens musicais (artistas ou álbuns) integrados via API externa.
* **5.2 Buscar artista:** O usuário procura especificamente por um artista no catálogo.
* **5.3 Buscar álbum:** O usuário procura especificamente por um álbum no catálogo.
* **5.4 Gerenciar avaliação:** O usuário visualiza e gerencia suas avaliações publicadas.
* **5.5 Escrever resenha:** O usuário redige e publica um texto opinativo sobre um álbum.
* **5.6 Editar avaliação:** O usuário modifica o conteúdo de uma avaliação ou resenha que já havia feito.
* **5.7 Excluir avaliação:** O usuário remove uma avaliação ou resenha previamente publicada.
* **5.8 Avaliar álbum:** O usuário atribui uma nota/avaliação a um álbum.
* **5.9 Favoritar álbum:** O usuário marca um álbum específico como um dos seus favoritos.
* **5.10 Desfavoritar álbum:** O usuário remove um álbum da sua lista de favoritos.

## 6. Conexão com o Spotify
* **6.1 Gerenciar conexão:** O usuário acessa o painel de gerenciamento da integração com sua conta do Spotify.
* **6.2 Conectar conta:** O usuário autoriza a integração da sua conta do Spotify com a plataforma Sonarfy.
* **6.3 Desconectar conta:** O usuário revoga a integração entre a sua conta do Spotify e o Sonarfy.
* **6.4 Sincronizar dados do usuário:** O usuário solicita ou dispara a sincronização de dados/histórico musicais vindos do Spotify.
