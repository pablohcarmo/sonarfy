# Sobre o Sonarfy
O Sonarfy nasceu como o Trabalho de Conclusão de Curso (TCC) do curso de Ciência da Computação da FAM - Centro Universitário.
O projeto foi desenvolvido para criar uma plataforma que permite musicólogos e amantes de música a compartilhar suas avaliações e opiniões de álbuns.


A escolha do nome Sonarfy vem da junção das palavras "sonar", que remete algo ligado ao som ou vibração,  o sufixo "fy" é a abreviação de "for you". Podemos dizer que algo como "som para você".
